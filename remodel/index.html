One-time setup needed

This copy is not connected to a Firebase project yet.

  1. Create a free Firebase project (Spark plan, no card).
  2. Enable Google sign-in and create a Firestore database.
  3. Paste the web config into firebase-config.js.
  4. Deploy the rules: npx firebase deploy --only firestore:rules
