Training Badge Styles

Three options for visually distinguishing the Kind / Badge values on training entries. Each option shown at production scale (9px), then again at 11px so you can see the icon detail clearly. Pick one and Claude ships it.

A Color-grouped (3 tones)

Cyan = ongoing structured training. Amber = short-form intensives. Magenta = performance milestones. Three colors total. Easy to scan, never noisy.

· How to pick

Honest reads:
  • Option A — best balance. Three tones give you scanning value (you can tell at a glance whether a row is a workshop, a class, or a performance) without looking like a rainbow.
  • Option B — useful if you imagine adding a lot more training entries (15+) where rich visual differentiation pays off. With 9 entries today, it can read busy.
  • Option C — most restrained. Keeps to brand cyan and uses prominence to communicate signal-vs-noise. Works well if you want to keep the page minimalist.
Icon size note: at the production 9px badge size, icons read more as visual texture than as readable iconography. They still help: gives the eye a shape to anchor on. At 11px+ (a small bump), icons become clearly identifiable. If you want, we could bump the badge font from 9px to 10–11px to make icons more legible — tell Claude which scale to use when picking the option.
