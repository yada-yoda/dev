Credit Tab Transitions

Four ways to handle the Film / TV / Theater / Commercial tab switching. Click between tabs in each demo to feel the motion. The recommended one is Option 3 (sliding pill + crossfade). Pick one and Claude ships it on the live site.

3 Sliding pill + crossfade (recommended)

The cyan pill slides between tabs so your eye can track it; panels crossfade so nothing hard-cuts. Container is fixed-height so the page doesn't shift.
