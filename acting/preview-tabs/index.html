Credit Tab Transitions

Four ways to handle the Film / TV / Theater / Commercial tab switching on the Selected Credits section. Click between tabs in each demo to feel the motion. Pick one and Claude ships it on the live site.

3 Sliding indicator + crossfade (recommended)

Combines both effects. The cyan tab pill slides between buttons so your eye can track it; panels crossfade so nothing hard-cuts. Container is fixed-height so the page below doesn't shift.
