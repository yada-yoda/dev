What's new

  • v0.8.2 — Each monitor card now shows its current value at a glance (the rate, price, or keyword state) and a thumbnail of the page — the ↻ refresh button updates both. Two reliability fixes: an empty read (page didn't finish loading) is now treated as a temporary error and retried, never a false “it changed” alert; and if a browser render fails, Spyglass falls back to the r.jina.ai reader.
  • v0.7.2 — Spyglass now renders JavaScript pages with its own browser, replacing the outside r.jina.ai service (which started rate-limiting). New Render in a browser toggle for JS-built pages — and Test it now / the pattern builder switch it on automatically when a value only appears after scripts run. Your bank-rate monitors were moved onto it.
  • v0.7.1 — Screenshots are much faster (a few seconds instead of ~25) and no longer come back blank on script-heavy sites — the capture now waits for the page's text to actually render instead of for network traffic to go quiet, which banking sites never do.
  • v0.7.0 — Four VisualPing-inspired upgrades: 📏 screenshot region picker (drag a box over a live screenshot; that monitor's screenshots crop to just that area), keyword direction (alert only when a phrase is added or only when it's removed — perfect for restock watching), Discord & custom webhook alert channels (set in ⚙ Settings), and schedule windows (limit checks to certain days/hours). Keyword monitors are now clearly labeled “Keyword / exact phrase”.
  • v0.6.1 — Added a Privacy, Terms & Disclaimer page explaining exactly what Spyglass stores, where it lives, and what it will never do (no analytics, no ads, no data sale) — linked from the new footer.
  • v0.6.0 — 📷 Page screenshots: when a monitor changes (or takes its first baseline), Spyglass photographs the real rendered page — see it in the change history and attached to alert emails; toggle it in the new ⚙ Settings. Sign-ups are now invite-only with an admin switch to reopen them, and Spyglass got its own 404 page.
  • v0.5.0 — ✨ Build it for me: no more writing regex by hand. Pick the Pattern type, type the value you currently see on the page (and optionally a word near it, like “APY”), and Spyglass generates the pattern, tests it against the live page, and fills it in — automatically switching to the rendered-page version when the site needs JavaScript.
  • v0.4.0 — The change history is now a real look-back log: the first check records a baseline snapshot (“started watching — value was X”), and timeline rows show the captured value with its date & time instead of just +N/-N counts. Click any row for the full before/after diff.
  • v0.3.0 — New Pattern (regex) monitor type that extracts a value (a rate, a price) and keeps tracking it as it changes — no re-arming needed, and the alert email shows old → new. Every monitor card gets a ↻ Check now button. Alert emails now include a Recent changes history.
  • v0.2.0 — New Test it now button in the monitor form: fetches the page and shows exactly what your selector or keyword would watch, before you save. Pasted DevTools class lists are auto-converted to real CSS selectors, and when a page hides its content behind JavaScript, the tester now tells you and suggests the r.jina.ai rendered-page trick.
  • v0.1.0 — First release: create page monitors, Google sign-in, and a dashboard. Server-side checking + email alerts arrive with the worker.
